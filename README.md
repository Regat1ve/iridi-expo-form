# Анкета iRidi для выставки

![CI](https://github.com/Regat1ve/iridi-expo-form/actions/workflows/ci.yml/badge.svg)

Бумажная «Анкета для выставок», перенесённая в веб-приложение для iPad. Сотрудник на стенде
заполняет анкету за посетителя, все записи падают в базу и выгружаются в Excel или Google Таблицу.

- `/` — анкета (9 вопросов как на бумаге), крупные элементы под палец
- `/admin?key=…` — все контакты таблицей, фильтр «Горячие», кнопка «Скачать Excel», формула для Google Таблиц
- `/qr` — табличка с QR-кодом для стенда: посетитель заполняет ту же анкету со своего телефона

## Что сделано под выставку

- **Не теряет анкеты без интернета.** Анкета сначала сохраняется на iPad (localStorage), потом
  отправляется на сервер; если Wi-Fi пропал, очередь досылается сама каждые 15 секунд и при
  возвращении сети. В шапке виден счётчик «Ждут отправки».
- **Без дублей.** id генерируется на iPad, повторная отправка того же id в базе игнорируется.
- **Страница открывается офлайн.** Service worker кэширует форму; на iPad её можно добавить
  на экран «Домой», и она запускается как приложение.
- **Google Таблица без настройки API.** `=IMPORTDATA("…/api/export?format=csv&key=…")` в ячейке A1.

- **4 языка, как у сайта iRidi:** RU / EN / DE / 中文. Язык берётся из настроек телефона,
  переключается кнопкой и запоминается на устройстве. В базу ответы пишутся по-русски, поэтому
  Excel остаётся одной таблицей с фильтрами, плюс колонка «Язык анкеты».
- **Горячие лиды.** Кто отметил «Нужно КП…», «хочу стать дистрибьютором» или «презентация
  pre-sale менеджера», подсвечен в админке и в Excel — менеджеры звонят им первыми.

## Тесты

`pnpm test` — проверка входных данных, логика горячих лидов, полнота всех 4 переводов.

`pnpm test:e2e` — Playwright против настоящего Postgres, на двух движках: WebKit (Safari на iPad) и Chromium:
- анкета попадает в базу и в Excel;
- пока страница не загрузилась до конца, поля заблокированы и введённое не теряется;
- **нет интернета** → анкета остаётся на устройстве, переживает перезагрузку страницы, после
  появления сети досылается сама;
- без телефона и email анкета не сохраняется;
- повторная отправка не создаёт дубль, мусор в запросе отсекается;
- немецкий посетитель видит немецкий интерфейс, в Excel попадают русские значения;
- телефон на китайском открывает анкету на китайском;
- горячие лиды отделены от любопытных;
- админка и выгрузка закрыты без ключа.

CI на GitHub Actions поднимает Postgres и прогоняет всё на каждый коммит.

## Стек

Next.js 16 · Postgres (Neon) · ExcelJS · Vitest · Playwright · Vercel

## Запуск

```bash
psql "$DATABASE_URL" -f db/schema.sql
DATABASE_URL=... ADMIN_KEY=... pnpm dev
pnpm test && pnpm build && pnpm test:e2e   # e2e ждёт DATABASE_URL с применённой db/schema.sql
```
